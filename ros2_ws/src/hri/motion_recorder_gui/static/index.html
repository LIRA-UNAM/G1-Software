Record

Teach mode: with motor output enabled the bridge only damps the joints while recording, so the limbs can be guided by hand. Only the checked limbs are sampled (20 Hz). Limbs tagged offline have motors without power or comms: their data would be junk.

Playback

Only groups contained in the selected recording can be played. With a home keyframe set, Play moves slowly home → to the recording's start pose, replays it at the recorded rate, then returns slowly home and holds (without home: start pose → play → start pose). Set home stores the current joint positions (online motors only); position the robot first, e.g. by hand in teach mode. Unselected groups hold their position. Reset stops what is running and returns slowly home (or to the start pose). Release lets the bridge damp the joints.
